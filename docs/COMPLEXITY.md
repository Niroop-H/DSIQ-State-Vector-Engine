# DSIQ representation complexity and numerical scope (v0.9)

Let n be the register width, G the number of bounded-arity elementary gates, D the depth and w the machine-word bit width. No claim is made that arbitrary circuits can be represented efficiently. The costs below are arithmetic counts and logical coefficient payloads; software objects, inputs, BigInt allocation, allocator overhead, runtime, hardware caches and RSS are separate. Gate count can be O(nD) for bounded fan-in and disjoint layers; non-Clifford count, topology and boundary queries govern actual complexity. A resource refusal is not a completed scientific result.

## Dense and component statevectors

Dense FP64 statevectors use 16 * 2^n bytes and O(G * 2^n) complex operations (bounded arity). Independent connected components of sizes w_j require 16 * sum_j 2^w_j bytes, and O(sum_g 2^w(g)) arithmetic. For a k-wire dense local matrix, work O(2^k * 2^w(g)) includes a full multiply, not bounded-arity gate cost. Factor planning uses a disjoint-set structure with O(n+G) operands and near-linear amortized union/find work for path compression (worst-case conservative O(nG)). Native component scheduling adds O(G+n) plan data and thread stacks. FP32 uses 8 bytes per complex entry and rounds each local operation to FP32.

## Affine Clifford / Affine phase

A stabilizer vector uses affine support x=A u xor b and quadratic mod-4 phase, with binary data plus phase exponent, O(n^2) bits. Elimination uses at most O(n^2) mask-row operations per gate/query, each operating on O(n)-bit masks (conservative O(n^2 ceil(n/w)) word work per solve, plus parity/population-count implementation cost). Non-Clifford parity phase adds O(t*n) bits for t retained odd mod-8 parity terms; the supported Gauss-sum reductions require their algebraic preconditions. A non-Clifford Hadamard crossing an incompatible parity direction rejects that representation. t may grow, and these restricted algebraic paths do not cover arbitrary gates.

## Frame factor

Maintain exact Pauli conjugation maps X_i -> C†X_i C and Z_i -> C†Z_i C by Clifford updates. For P=i^p X^a Z^z and a Hermitian generator, rotations have R_P(theta)=cos(theta/2) I - i sin(theta/2) P. Factor the support graph of the conjugated rotations, not the physical wires. The full state is C times a tensor product of the component vectors (and explicitly tracked global phase). All component entries are retained. The maps take O(n^2) bits, the retained rotated-generator ledger O(mn) bits for m rotations plus O(G) source gate metadata; coefficient payload is 16 sum_j 2^w_j. Map compilation for bounded-arity Clifford gate takes O(ceil(n/w)) bit-word XOR plus parity cost; converting conjugated rotations via the stored generator images and listing support is O(n ceil(n/w)) per rotation in a conservative model, plus union/find. Evolution cost is O(sum_j m_j 2^w_j). For monomial final C the physical basis query inverts a binary affine map and multiplies one coefficient per factor (O(n^2) bit operations conservatively plus factor work). Nonmonomial C queries contract the affine stabilizer C†|x> against component factors. Its free binary variables and scopes define a new contraction order with separator k; use the contraction cost below, not the component evolution cost. Pauli expectations conjugate the string into the reference frame, then contract each component: O(n^2) bit ops and O(sum_j 2^w_j) complex operations. Sampling is currently implemented only for basis-preserving C, with local CDF arrays (8 sum_j 2^w_j bytes) and binary-map readout. Nonmonomial sampling rejects rather than inventing output. The whole circuit is retained, and original gate identities are never pattern-replaced with benchmark answers.

## Weighted amplitude DAG, Coherent products and Replay

DAG node count B depends on repeated normalized subfunctions, with edge coefficients and hash-map metadata. A gate can visit O(B) nodes and create pairwise subproblems, up to O(B^2) distinct pair sums per combination; actual recursive arithmetic depends on all visited intermediate pairs and is conservatively bounded by full exponential expansion. The node cap alone does not bound arbitrary JS recursion or total RSS. Coherent product terms T retain O(T(n+E)) fields for E phase edges per term; generic overlap can contract T^2 term pairs and require exponential summation over binary variables. T can grow exponentially with gates. Replay branches over all predecessor indices; if h gates admit two predecessors, at most O(2^h G) path-prefix work (times bit-word operations), bounded stack O(G ceil(n/w)) words plus the circuit and accumulator. No time bound polynomial in n or D is asserted.

## Contraction and Pair contraction

The compiled path sum has O(n+G) binary boundary and internal variables for bounded arity. For an elimination order, if variable v has k_v remaining neighboring variables and d_v incident factors, work is O(d_v * 2^(k_v+1)) complex operations. Live coefficient payload at each step is 16 * sum_f 2^arity(f), counting both old factors and an allocated output until the old inputs are released. Scope planning is a heuristic; work depends on frontier sizes and candidate orders, and is capped explicitly. The GF(2) parity compiler substitutes linear constraints before contraction; its scopes may grow, and the same exponential separator dependence remains. Fixing s binary variables coherently slices the original computation into at most 2^s evaluations; sums include all slices and may take exponential time. The double layer for a probability or Pauli expectation can have larger width; one sample requires O(n) marginal queries absent cache hits. Causal-cone elimination removes only exact U† I U factors outside the support.

Pair contraction retires all indices that occur only in the chosen input pair, or unary factor. For union arity u and retained arity k, there are 2^k outputs, each with 2^(u-k) contributions: O(2^u) arithmetic, plus index lookup preparation. Temporary index tables allocate 8*(2^k + 2^(u-k)) bytes, in addition to output and live inputs. A complete scope-only multi-start planner records peak coefficient-plus-index bytes and predicted products before execution. It computes candidate pair costs by inspecting scopes and adjacency, not amplitudes; O(trials * F^3 * a^2) is a conservative bound for F input factors and maximum arity a (the explicit planner work limit can reject earlier). Chosen width and budget forecasts are not optimal lower bounds. Slicing with pair ordering is not yet implemented for all failures; unsupported resource cases reject without partial values.

## Dyadic and Certified arithmetic

Dyadic path coefficients are (a+i b) 2^e with arbitrary integer a,b. Each addition or multiplication depends on integer bit length L, not constant time. For schoolbook arithmetic, add is O(L), multiply O(L^2); actual BigInt algorithms vary. Payload per coefficient grows with L; aligned exponent shifts may also grow it. Fixed bit/work/payload budgets reject overflow rather than truncating. For represented binary64 gate matrices, the path evaluation is exact within admitted bounds. Ideal trigonometric gate-entry error is separate. A conservative certified connected circuit bound e propagates e' <= e + delta + e delta, where delta is a sum of outward-rounded componentwise gate-entry errors and hence an operator-norm upper bound. State projection error is calculated by exact dyadic comparison; a norm-one Pauli expectation error is at most (2+e)e plus final projection error. The certified factor implementation includes local rounding allowances and product bounds. Certificates admit a documented domain of input angles/operations; other public representations are not implicitly certified.

## Gaussian TFIM and adjoint Pauli

The fixed analytic Gaussian chart uses O(n^2) matrix storage, O(n^3) arithmetic for the matrix exponential and solve; an occupation-k Pfaffian costs O(k^3) arithmetic. Its scope is a specified integrable Hamiltonian, not general simulation. An adjoint Pauli expansion with T live terms stores O(Tn) bits plus coefficients, updates in O(sum_g T_g * ceil(n/w)) bit-word work plus associative-map operations and arithmetic. T may double per noncommuting rotation. It is an observable evaluator only.

## Entropy and Worst case

For a bipartition with Schmidt coefficients lambda_j, exact rank R is at least 2^S where S=-sum_j lambda_j^2 log2(lambda_j^2). An exact matrix-product-state bond across that cut requires at least R; DSIQ does not deliberately truncate it. This is not a general bound on all representations: Clifford entanglement, graph phases or algebraic permutations can reach large S with polynomial descriptions. Conversely low entropy on one cut does not force small contraction widths elsewhere. Physical gate depth alone cannot bound the required resources; circuit topology and the chosen representation and query matter. For a generic n-qubit pure state there are 2^(n+1)-2 real degrees of freedom; an explicit FP64 array requires 16*2^n bytes. A succinct gate program can be an exact implicit specification, not a guarantee of efficient amplitude extraction, sampling or materialization. No claim of arbitrary large-state compression, a universal polynomial-time solver, or provable general efficient evaluation follows from our structured tests. Fully connected deep random circuits may exceed any practical chosen resource budget. #70 remains unpassed unless the full benchmark (including required intermediate evolution) actually completes without prohibited shortcuts.

## Rank-reduced frame and commuting logical measurements

Let r be the rank over GF(2) of the reference-frame X masks. An invertible CNOT row transformation D maps their span into r coordinate axes. The identity D R_P D† = R_(D P D†) guarantees exact basis equivalence. A Z mask on the inactive n-r wires acts as +1 on their fixed zero computational bits and can be removed from rotated generators, not from general physical observables. Row operations preserve phase when conjugating X^a Z^z by a CNOT. The full support remains encoded by the final Clifford C D†. r may equal n, even at small physical depth.

Binary elimination uses O(m r) mask XORs for m rotations; the row transformation requires at most O(n r) CNOTs. The current implementation explicitly applies every transformation to O(n+m) stored Pauli masks, with conservative O((n+m) n r) mask operations, plus parity and bit-index cost. Coefficient payload still follows 16 sum_j 2^w_j across transformed components, with active component width at most r (plus singleton zero wires). Metadata and BigInt memory are separate.

For a nonmonomial final C D†, output measurement is the joint distribution of n commuting Pauli images. Let s be the rank of their inactive X masks. Any product containing a nonzero combination of the s pivot rows has a nonzero inactive flip and zero expectation on the inactive |0> register. By the binary Fourier expansion of the joint distribution, these transformed s outcome bits are uniform and independent of the remaining rows. Kernel rows reduce to commuting Pauli operators on r active coordinates, which have at most r independent symplectic generators. Their projective outcomes determine every dependent row including its sign. The sampler explicitly constructs a full active vector and three scratch vectors, requiring 64*2^r extra coefficient bytes; row elimination stores O(n^2) bits or dependency indices and can cost O(n^2) mask operations. For each sample, at most r dense projections cost O(r 2^r) arithmetic plus row-dependency reconstruction, bounded by O(n^2) bit operations. The implementation refuses excessive rank, memory or work. This generalization applies only to admitted rank-reduced states; it does not guarantee efficient sampling for arbitrary circuits.

## v0.10 monomial streaming and exact native-host bond networks

For a basis-preserving Clifford, the inverse-frame stabilizer has rank zero and only one computational-coordinate assignment contributes. If `P = C† X^b C = i^p X^a Z^z`, the internal index for output basis b is `offset XOR a` and the phase correction is the complex conjugate of the inverse Clifford's global eighth-root phase times `i^(p+2 parity(z&offset))`. Multiply one complex coefficient from each stored component. The browser query accumulates magnitude logarithmically and returns component-underflow metadata; no output tensor allocation. The C block interface supports 1..63 wires with unsigned indices and at most 2^20 entries per call; it returns an error on detected total-product underflow or nonfinite output. It does not return a logarithmic representation. Pauli lookup tables cost O(256 ceil(n/8)) entries; component payload remains 16 sum 2^w_j bytes. A streamed traversal of all physical amplitudes still uses exponential time even if its output buffer is fixed.

A singly controlled operation admits `P0 ⊗ I + P1 ⊗ U`. Native-host bond contraction represents the connecting index as a dimension-2 exact bond, and uses explicitly fused one-wire intervals. An alternative compact network retains shared control variables and substitutes only exact pinned values. The affine variant can eliminate exactly recognized unit-weight XOR constraints with sparse GF(2) substitutions; local table arity is limited to eight, and uneliminated constraints remain tensors. These transformations preserve the path sum algebraically, not necessarily bitwise under FP64. Planning inspects scopes; randomized multi-start heap heuristics are not optimal. Each pair costs up to O(2^|union|) products, total live array bytes grow with retained arity; transposition/normalization scratch, library working memory, Python objects and OS RSS are separate. Native-host numerical work uses NumPy/BLAS for ordinary tensor arithmetic, with no third-party quantum simulator dependency. The budget is an array-plan check, not an enforced total process limit. Finite binary64 dynamic ranges still apply, and this amplitude-only backend does not provide universal sampling, interval certificates or deep chaotic-circuit completion.

# Claude-assisted independent Diamond review

Give the following brief to Claude in an evaluator-controlled environment after both parties agree on the candidate commit and the sourceSHA256 produced by the freeze command in [the protocol](INDEPENDENT-REVIEW.md). Keep private answer files and generator seeds outside the operator's checkout. The evaluator should record Claude's role, model, date, reference software versions and hardware.

> Design 20 new mystery circuits of 50–100 qubits covering QFT, RCS, QAOA and uncompute. Follow the strict challenge and reference JSON schemas in the independent-review protocol. Choose the circuits without inspecting DSIQ results. Include phase-sensitive complex amplitudes, nontrivial Pauli observables, and intermediate forward queries for uncompute. Include nonzero reference probes that would catch an engine returning zero. Specify each family's topology, effective width, depth and coverage. Use q0 as the rightmost bit. Record how you lower composite gates and which angle convention you use.
>
> Write and run an independent oracle or derive and cross-check analytic answers. For each circuit preserve the generator, seeds, oracle code, command, version, precision, tolerance rationale and raw output. Check wire order and phase conventions on small dense circuits first. If an oracle cannot resolve a value within the required tolerance, record the unresolved case. Never invent a numerical answer or replace a failed case after seeing DSIQ results. Predeclare any RCS sampling tests, sample counts and statistical acceptance rules separately.
>
> Prepare challenge.json and private reference.json. Follow the strict commit command. Initially deliver only challenge.json, commitment.json and their authenticated hashes to the operator. Retain reference.json, reveal-private.json and private generation records until the operator returns the output manifest hash. Then verify, reveal and score. Report every timeout, missing query and numerical mismatch with the circuit and query IDs.

The independent evaluator reviews the oracle, workload coverage, results and [attestation](REVIEWER-ATTESTATION.md) for #100. For #105 a separate engineering team must build the same commit on clean hardware and reproduce the benchmark under the documented conditions. Share the pinned source, environment record and raw evidence with that team.

# DSIQ — experimental numerical architecture (MAH Quantum)

## Scope and mathematics

All kernel code is independently authored for this project, using standard quantum mechanics and complex arithmetic. No third-party quantum simulation library is called. Weighted decision diagrams and sum-over-path algorithms are established research techniques; this prototype does not assert invention of either or validate a patent claim. The earlier affine-phase/Clifford reference-frame master equation is a research direction, not the algorithm implemented here.

For a level-q node, the amplitude function is `F_q(x) = w_(x_q) F_(q+1)(x)`. Each node stores two complex edges and a scalar phase/norm factor. Identical normalized suffixes are interned using exact Float64 keys (not tolerance-based merging). An uncontrolled 2x2 gate acts on the two child functions by their coherent linear combination; a controlled gate with controls preceding the target in DAG order traverses only enabled branches; otherwise it applies `I + P_controls (U-I)` with the computational-basis projector. SWAP is three CX gates. All branching phases are retained, with ordinary floating-point error. Samples descend through squared edge magnitudes because child functions are normalized. The logarithmic amplitude query accumulates log2 magnitude and phase along the chosen path. Returned real/imag components may underflow while log magnitude remains meaningful.

If the configured node count is exceeded, the kernel discards the DAG and accepts the remaining gate sequence. For a requested basis state it replays `⟨x|U|0⟩ = Σ_y ⟨x|G_m|y⟩ ⟨y|G_(m-1)...G_1|0⟩` via resumable depth-first traversal, summing complex terms with compensated addition. This fallback does not allocate a dense global statevector and can yield progress; it may take exponential time and use memory proportional to circuit size and stack depth. Replay Float64 products can underflow; no statistical approximation is silently substituted. Replay sampling is unavailable. Replays are cancellable, but do not persist checkpoints across a page reload.

## Interface and resource contract

- 1–4096 admitted logical qubits, 100,000 expanded operations, configurable DAG node count, up to 1024 samples. Admission bounds are not performance guarantees.
- Node count cap is not a byte/RSS limit. JS objects, maps, circuit storage, memoization, worker and replay stack all consume RAM independently. A 4 MiB native fixed-arena implementation is not yet available.
- Supported textual subset: one quantum register; H, X, Y, Z, I, S/SDG, T/TDG, RX/RY/RZ, P, U/U3, CX/CZ, CCX, SWAP, barrier. Angles use numerical literals, pi, arithmetic and parentheses. No explicit measure, reset, classical feedback, or noise; samples are final full-register computational-basis samples. q0 is rightmost.
- Local Web Worker supplies progress, cancellation and JSON evidence including input source and seed. A local run is not hardware execution. The legacy workbench remains unchanged except the added DSIQ entry and a parent quota reservation bridge. Static standalone assets are inspectable and can be reached directly; the quota bridge is not an enforceable access control. Do not expose the proprietary kernel publicly until deployment/IP review.

## v0.4 — adaptive representations, scaled replay and trajectories

This supersedes the v0.3-only execution path. All new kernel code is independently implemented; standard quantum-mechanical and algebraic techniques are not claimed as invented by MAH Quantum. There is no external quantum-simulator production dependency. ### Lossless adaptive controller

`executeAdaptive()` tries a symbolic product phase backend when gate signatures allow it, a coherent phase-product sum for appropriate local/diagonal/controlled workloads, and the planned weighted DAG. On a representation boundary the unchanged circuit is rebuilt in another representation; no benchmark answers, tolerance-based merge, bond truncation, or inverse circuit cancellation is used. If all compressed representations fail, the DAG's path replay remains available. Attempts and reasons are exported. Coherent representation selection is bounded to at most 256 qubits and 256 terms in the current adaptive worker; the API has independently configurable term and contraction bounds. These are counts, not byte limits. A failure to contract or a Float64 product underflow is a resource/numerical boundary, not a valid zero output. Tests of each representation are separately identified. In general, no backend promises efficient arbitrary-depth universal circuits.

`phase-product.mjs`: A product state is encoded as definite basis factors or balanced factors `(abs0> + exp(i*pi*r) abs1>)/sqrt(2)`, plus an exact rational global phase. `r` is a reduced BigInt fraction modulo 2; local and controlled phase updates use exact rational algebra when a control/target is definite. H on a basis factor creates a balanced factor, and H on relative phase 0 or 1 (modulo 2) converts back to a definite basis factor. Other states/entangling operations trigger representation fallback. The rational metadata originates from explicit pi expressions or an explicit API fraction, never by snapping a nearby raw Float64 angle to a rational. Every QFT gate is applied, including the full forward and inverse; no inverse-pair elimination. The tested QFT begins in a computational basis state, and exact dyadic QPE uses an eigenstate. This does not claim arbitrary entangled-input QFT. For `n` factors and maximum rational bit size `B`, representation storage is O(nB) bits, with arithmetic cost depending on integer/rational operations; the query is O(n) rational additions plus amplitude conversion. Linear complex outputs remain Float64; logarithmic magnitude can represent smaller values.

`coherent.mjs`: the state is `f(x) = sum_t w_t prod_q v_(t,q)[x_q] * (-1)^(sum_(u,v) in E_t x_u*x_v)`. CZ toggles an edge; local diagonal operations act on local factors. Non-diagonal gates at an incident vertex expand the two input branches, absorb their phase dependencies in neighbor factors, then apply the local matrix. Controlled operations use `U_c = I + Pi_controls (U-I)` retaining the coherent complex contributions; definite controls avoid expansion. Custom matrices up to 32x32 are validated for unitarity (1e-12 column overlap tolerance) and applied by coherent row sums/projections, with atomic failure if the term cap is reached. This is a programmatic API, not arbitrary matrix text import. Query work is O(T(n+E)) for T terms with bounded E per term. Overlaps/Pauli/projector contractions use pairwise term products. When graph edge differences cancel under Pauli translation, the contraction factorizes. Otherwise it enumerates the variables involved in the residual quadratic graph, capped at 18 variables by default. Worst-case contraction remains exponential and term count can grow exponentially. No threshold-based coefficient pruning; Float64 arithmetic operations can nonetheless round, cancel or underflow. Coherent sampling is exact algebraically for a single phase-decorated product term (phases do not affect computational probabilities); for multiple terms, it contracts conditional projectors and fails on invalid probabilities or excessive residual graph difference.

`observable.mjs`: separate observable-only engine. Reverse conjugation of a Pauli P by a Pauli rotation R_Q(theta) is P for commuting Q and P, otherwise cos(theta)P + i*sin(theta)QP. Clifford conjugation updates binary X/Z masks and phase; matching Pauli terms merge by exact key, with Float64 coefficients. Capped terms and updates fail explicitly. The initial computational basis expectation is zero for terms with any X component, otherwise the Z sign. This computes an observable of the same circuit without claiming amplitude reconstruction or sampling. The UI `Pauli only` action explicitly reports no amplitude, norm, or samples. Worst-case operator expansion remains exponential. Analytic p=1 QAOA reference checks use two specified triangle-free 50-node graphs; no claim for arbitrary-depth QAOA.

`scaled-replay.mjs`: depth-first path replay now scales complex branch products by an integer binary exponent before multiplication. Reachability masks reject an intermediate predecessor bit if no earlier gate could have flipped it from zero; this is exact structural support, not approximate amplitude pruning. The sum of represented binary64 leaf components is accumulated in bounded BigInt binary integers; path products still round, and no certified forward-error bound is claimed. The visit and accumulator budgets cause explicit exceptions, never a partial amplitude reported as complete. The accumulator exponent span limit is 262144 bits by default; circuit history, stack and BigInts consume additional memory. At 1200 product qubits a forced replay produced log2 magnitude -1200.0000000000002 in 1201 visits; real and imaginary Float64 components may underflow and the result flags component underflow. Replay cannot currently produce full-state sampling and remains potentially exponential in time. No disk paging, network offloading, or persistent checkpoints are introduced; this is a source-level design statement, not a completed OS audit.

`trajectory.mjs`: the worker recognizes a restricted single quantum/classical register OpenQASM subset with measure/reset and integer equality-conditioned gate statements (QASM 2 whole-register and QASM 3 indexed assignment/condition syntax). No general OpenQASM 3 classical language, arbitrary branching, noise, or full density-matrix mode. Reset is a measurement trajectory plus conditional X. Conditional amplitude and measurement event logs correspond to the first trajectory; shot distributions independently rerun the program. A resource boundary after collapse raises an error, not a replay of the uncollapsed circuit. The API also supports a zero-qubit vacuum in the DAG kernel (textual QASM still requires 1–4096). Histogram sampling skips deterministic runs only when a branch coefficient is exactly zero; it advances RNG only at stochastic nodes, with its own reproducibility convention.

## v0.5 — affine phase, factor statevectors and native CPU arena

### Affine Clifford statevector

The representation is `psi(Au xor b) = 2^(-r/2) exp(i*pi*gamma/4) i^Q(u)`, zero off the affine support. A has independent binary columns indexed by the live coordinate mask, Q is quadratic over binary variables modulo 4, and gamma is modulo 8. X updates the affine translation; CX/SWAP update affine rows; S/Z/CZ add exact linear/parity-product phases. Y/CY preserve their global phases. H introduces a coordinate y and the factor `(-1)^(x_q*y)`. If the old support projection onto the other wires loses rank, the unique null direction v is eliminated: summing its binary variable gives `1+i^l*(-1)^B`. For even l, this imposes a parity constraint (or vanishes); for odd l it contributes a sqrt(2) magnitude and exact eighth-root phase, plus a linear phase of B. Only rank-many free coordinates remain. Basis queries solve binary linear equations, and norm is exactly one by the maintained affine invariant. Sampling selects independent uniform free coordinates. Nonzero amplitudes export exact algebraic descriptors (`sqrt2Power`, `phaseEighthTurns`) alongside rounded Float64 outputs, not an all-mode forward-error certificate. The Pauli expectation follows by solving the support displacement and summing its linear phase. Storage uses O(n^2) bits for binary rows and phase adjacency, plus JavaScript object/BigInt overhead and a cached solve basis. Gate and query costs depend on binary rank and mask width; preprocessing uses Gaussian elimination. No dense 2^n coefficient array is allocated in this mode.

### Affine-phase extension

Add an exact phase `L(u) = sum_j k_j parity(m_j & u) mod 8`. The amplitude is `2^(-r/2) exp(i*pi/4*(gamma+2Q(u)+L(u)))`. T/TDG change integer parity coefficients, duplicate masks combine modulo 8, and even coefficients fold losslessly into Q. When an H would eliminate a support direction v on which an odd parity term varies, the backend throws a representation boundary; adaptive execution retries another representation using the original circuit. There is no numerical tolerance used for this decision. For a Pauli displacement v inside the support, `L(u)-L(u xor v)` is a sum of terms `k*(2 parity(m & u)-1)` over masks with parity(m & v)=1. Thus the phase difference reduces to a quadratic modulo-4 polynomial with a known global eighth-root phase. Its normalized Gauss sum is evaluated by binary variable elimination: an odd diagonal yields a sqrt(2) factor and parity phase, an even diagonal constrains another variable or gives a zero/full sum. The exact magnitude scale and phase are converted to Float64 at output. Space for the extra parity terms is O(t*n) bits and bounded by the configured term count; time depends on rank, mask population and t. General Clifford+T with Hadamards crossing arbitrary non-Clifford dependencies is not efficiently solved by this method. No claim of novel mathematical prior art is made.

### Factor statevectors, FP32 and native execution

A union-find plan computes the connected components of the circuit interaction graph. For an initially separable computational-basis register, no gate joins these components; therefore the global state remains their tensor product, and every local circuit gate is applied to its complete component vector without dropping small amplitudes or entanglement within a component. Component order is transparent in external wire labels. The coefficient memory is `16 sum_j 2^(w_j)` bytes in FP64 or `8 sum_j 2^(w_j)` bytes in FP32, where w_j is component width. Gate execution is O(2^w_j) per 1-qubit/controlled gate in its component. A single full-width connected component can still be exponential and is rejected before allocation if its coefficient budget is exceeded. FP32 uses Float32Array storage with Math.fround arithmetic; matrix generation and scientific reductions use Float64. This mode is explicitly selected in the workbench and refuses unsupported precision paths; it does not silently substitute FP64. Factor sampling compiles a separate budgeted Float64 CDF and rejects a nonzero probability if the CDF cannot resolve it. Optional fusion only combines adjacent unconditional single-wire gates by matrix multiplication: compile/execute timings and source-operation counts are reported. It is not used to pass the deep uncompute requirement.

`native/dsiq_factor.c` is a stand-alone POSIX/Linux C11 CPU implementation for preplanned factor circuits, not the browser worker and not a universal native affine/DAG kernel. It uses a fixed 4,194,304-byte coefficient arena in static storage, validates factor width, wire membership and every streamed gate, rejects oversized plans, and uses no disk scratch or external simulator. Linux seccomp denies socket creation (with a local EPERM probe); this is a scoped guard, not a comprehensive host security audit. Process RSS includes executable/runtime pages and may vary with the host. Coefficient arena capacity and committed resident memory are distinct; a run using a subset of the arena need not touch every page. The native audit checks `/proc/self/status` RSS/HWM/VmSwap where available, against the independently executed JS factor state and 1,000 sequential native programs. Compile: `gcc -std=c11 -O3 -Wall -Wextra -Werror -ffp-contract=off native/dsiq_factor.c -lm -o dsiq-native`; reproduce: `node tests/native.test.mjs`. No hard total-process RAM guarantee, full OS paging/interface audit, GPU support or MPI state evolution is claimed. `native/batch.mjs` is a Node worker-thread batch amplitude query implementation over a bounded shared read-only snapshot; result ordering and 1/8-worker determinism were compared to serial queries. Worker startup/IPC are included in elapsed time.

## v0.6 — bounded circuit contraction, analytical fermionic evolution and native parallelism

The new contraction path evaluates a basis amplitude directly from the input circuit. For each gate g, introduce a binary output variable on each changed target wire. With the input and output boundary bits fixed, the amplitude is the sum over the internal binary variables of the product of gate matrix elements. Diagonal gates reuse their wire variable. Controlled gates use the appropriate conditional matrix (identity when disabled); SWAP permutes wire labels. Variable elimination replaces all factors containing one binary variable v by the factor `F(s)=sum_{v=0,1} product_j f_j(v,s)`. Minimum-neighbor-size ordering is a heuristic, not an optimal-width guarantee. Coefficients carry binary scale exponents; no amplitude thresholds or bond truncations are used. Underflow/dynamic-range failures detected by the implementation cause explicit errors. If an elimination cannot fit the admitted tensor coefficient budget, coherent slicing fixes an internal variable to 0 and 1, evaluates both subproblems, and sums their represented complex values with a scaled integer accumulator. No slice may be discarded; exhausted work, variable, coefficient or slice budgets give no completed amplitude. This is amplitude-query functionality, not a universal sampleable statevector, and full forward-error bounds are not established. Metadata, runtime memory, stacks and source circuit storage are excluded from tensor-byte telemetry. The browser worker offers explicit contraction and amplitude-only fallback; it does not advertise sampling or Pauli expectation support from contraction.

The independent `GaussianTFIM` implementation evolves `H=-sum_j h_j Z_j - sum_j J_j X_j X_(j+1)` from the computational vacuum, with open boundaries. Under Jordan-Wigner, `H=(i/4)c^T A c` for a real skew-symmetric Majorana generator A. The Heisenberg transformation is `R=exp(A*t)`. A 24-term Taylor expansion is evaluated only when `||A*t||_infinity <= 0.5`; its exact-arithmetic remainder is at most `exp(0.5)*0.5^25/25!`. This analytical series bound excludes floating-point rounding and downstream matrix solve/Pfaffian errors. In the admitted vacuum chart, the Bogoliubov blocks P,Q give an antisymmetric pairing matrix `Z=-P^-1 Q`; the vacuum amplitude is the continuous square root of `det(P)` in this chart. Even-occupation amplitudes are the vacuum amplitude times the Pfaffian of the occupied-index submatrix of Z; odd amplitudes vanish. The full Majorana covariance and energy are calculated from R. The solver refuses evolution outside its chart rather than extrapolating or using Trotter steps. The module is currently a programmatic backend, not an arbitrary Hamiltonian simulator or a graphical sampling mode. Independent tests use SciPy spectral and small dense spin-space references, plus a long-double banded series/Neumann reference for relative comparison of tiny values. The use of established fermionic/variable-elimination mathematics is not a claim of original mathematical invention.

Direct multi-controlled RY is supported by the parser as the `mcry` extension and implemented without a subtraction-based inverse decomposition; test circuits prepare Dicke states via actual gates. This extension is not stock OpenQASM syntax. Native `dsiq_parallel.c` assigns complete disjoint factor components to pthreads. Component writes are disjoint and operation order inside each component is unchanged; deterministic output is checked across 1, 8, 32 and 128 threads. MPI and arbitrary connected-state parallelism are not implemented. `vector_stream.c` independently evolves local source-scatter reference coefficient arrays and visits every basis index of structured 25- and 30-wire circuits, comparing each reconstructed value. It avoids a dense global allocation, but it is not a comparison to Aer, cuStateVec, QuEST or Intel-QS, nor a general global dense test; the two product reconstructions share the product ordering.

### Complexity and memory scope

Let n be qubit count, G the number of gates, w_j the widths of actual disconnected components, B the allocated DAG-node budget, T the coherent term count, s the number of fixed slice variables, and k the largest separator in the selected contraction order. All arithmetic counts refer to fixed-precision complex operations unless explicitly described as binary operations; actual JS object sizes, integer exponents, GC and OS behavior are additional costs. These are representation bounds, not a claim of a polynomial bound in n or depth for arbitrary circuits.

- Dense: 2^n complex coefficients, O(2^n) work per bounded-arity gate. Factor: sum_j 2^w_j stored coefficients; work O(sum_g 2^w(g)) for bounded-arity gates, with full local coefficients retained. Entanglement across the chosen logical cut can be high even with small components. General custom k-wire matrices cost more. Native assignment has the same arithmetic count with additional plan storage O(G+n), thread stacks and scheduling overhead.
- Affine Clifford: O(n^2) bits plus implementation metadata/cached solve basis; a Gaussian-elimination solve uses at most O(n^2) mask-row operations across O(n)-bit rows; actual parity and BigInt cost must be included. Affine-phase adds O(t*n) bits for t parity terms, with term/rank-dependent elimination costs. The backend is not closed under arbitrary non-Clifford gates.
- Weighted DAG: O(B) node storage plus edges, weights, memo tables and circuit log. Gate application costs depend on the number of distinct visited subproblems; a node cap is not a universal bound on intermediate memo/work or total resident memory. General DAG growth is exponential.
- Coherent representation: O(T*(n+E)) stored factors/edges when at most E phase edges per term; overlap may require evaluating T^2 term pairs and exponential binary sums. T can double with branching gates. Replay: at most exponential paths in the number of gates with two possible predecessors; full path stack and history depend on G and n rather than a dense state array. Finite visit and precision/accumulator limits still apply.
- Circuit contraction: coefficient storage 16*sum_f 2^arity(f) bytes over live tensors, including the newly allocated elimination output before releasing its inputs. At elimination i with neighbor count k_i and d_i incident factors, contraction uses O(d_i*2^(k_i+1)) complex operations plus factor-index construction and order selection. Slicing can require 2^s evaluations; its worst-case time is exponential. Logged tensor bytes are not total RAM. Neither gate depth nor entropy alone characterizes general contraction width.
- Gaussian TFIM: O(n^2) matrix storage and O(n^3) arithmetic for the fixed-order matrix exponential/linear solve; one amplitude with k occupied sites uses O(k^3) Pfaffian arithmetic. Scope is the above integrable Hamiltonian and bounded chart, not arbitrary circuits.

The full 100-qubit 100-layer random uncompute remains unresolved. Generic contraction was verified on the first three random layers of the same generator; at four layers DSIQ computed a query but the independent reference exceeded its admission bound, and at five layers DSIQ hit the 4 MiB tensor coefficient limit. Identity cancellation, approximation and omitted intermediate states are not used to pass #70. Third-party reference tooling, full hardware audits, blind circuits and independent replication remain separate evidence gates. No unconditional 4 MiB total-process guarantee, certification, patent novelty or production full-frontend verification is asserted.


## v0.7 — relaxed resource policy and query-complete contraction

The user-directed 4 MiB target is no longer a general admission limit. Numerical coefficients default to 64 MiB; explicit browser queries allow up to 512 MiB. Work, slices, integer precision and JS runtime limits remain enforced separately. The standalone Linux runner defaults to 2 GiB address space and refuses network socket creation and writable scratch opens through inherited seccomp restrictions. This is a measurement harness for the trusted kernel, not a general-purpose security sandbox. No physical-memory guarantee follows from an address-space limit alone; the audit records observed RSS, swap, compute-phase disk I/O and interface counters.

For normalization, diagonal marginals and Pauli observables the double-layer contractor inserts an output operator between the circuit and its adjoint. An amplitude is a one-layer contraction; a probability is a sum over the squared absolute values, not a sum of amplitudes. Conditional sampling uses a chain of prefix marginal ratios. Causal-cone elimination is exact for unitary gates; no threshold truncation or approximate bond cap is used. The two-layer factor graph may have a larger separator than the one-layer graph. A full sample requires at most n+1 marginal contractions absent cache hits. Finite arithmetic and aggregate work limits apply; requests that cannot complete return a resource boundary.

The parity compiler represents live wire bits as affine GF(2) forms. X toggles a constant; CX XORs two forms; SWAP exchanges them. Other gates contribute complex factors. Fixing output bits produces linear equations, which are eliminated over GF(2). The remaining factors are functions of free variables; coefficient storage is exponential in the chosen separator width, not necessarily the original qubit count. Dense local factors still require exponential storage in their arity. Scope-only ordering estimates coefficient storage before allocation and can reject a predicted over-budget plan. Estimates are specific to the heuristic chosen, not lower bounds, and exclude metadata.

The exact-dyadic path converts the finite binary64 matrix entries actually supplied by the compiler to complex integers times powers of two. Addition aligns exponents and multiplication uses integer complex arithmetic, retaining every represented contribution. BigInt coefficient sizes and intermediate allocations depend on exponents and operation count; bit, payload and work limits prevent unrestricted growth. Exactness is with respect to these represented gate entries, not ideal irrational trigonometric values. The binary64 projection can underflow; the retained mantissas and exponent are the authoritative result.

The certified FP64 component path separately bounds ideal gate-entry errors for admitted binary64 input angles, using outward-rounded interval operations and Taylor remainders for trig. If the numerical gate differs from the ideal unitary by operator norm at most a and the local arithmetic error is bounded by delta, state error evolves as e_next <= (1+a)e+a+delta. Factor products and Pauli expectations propagate conservative norm bounds, with |<P>-<P_ideal>| <= (2+e)e for norm-one P when the full state error is e. The certificates are scoped to the admitted factor path; no all-backend certificate or bound on user input rounding is claimed. The tests compare to 100-digit mpmath and exact Python Fraction references; those are test-only dependencies.

The seeded 100-wire random uncompute remains unsolved. Two contraction representations agree on a four-layer prefix (600 gates). A selected ordering for the fifth layer forecasts roughly 384 GiB of coefficients; this is a heuristic forecast, not a mathematical minimum. No inverse-circuit cancellation is credited as executing the full forward and reverse workload. The original Diamond-105 criteria are unchanged. Full UI build, named external engines, GPU/MPI and independent peer audits remain outstanding.


## v0.8 — Clifford reference-frame factors and pair contraction

For U=C R(P_m)...R(P_1) up to a tracked scalar phase, maintain binary Pauli images under C†. A physical rotation is conjugated through the current Clifford; components are connected by the conjugated Pauli support, not by physical interaction edges. Dense FP64 local amplitudes are evolved without intentional pruning. Output amplitude is the inner product with C†|x>, evaluated as an affine quadratic phase sum over exact frame components. Basis-preserving final Cliffords support direct transformed sampling; nonmonomial final Cliffords support query and Pauli evaluation but reject frame sampling. Each query and coefficient plan has explicit limits. The workbench exposes frame execution and attempts it after adaptive failures for zero-shot jobs. The pair contractor merges factors and eliminates every variable whose remaining appearances are in the pair. Its forecast includes coefficient arrays and temporary integer-index lookup arrays. Budget-limited pair planning is not a lower bound or a guarantee of completion. Pair mode does not yet support all forced slicing boundaries.

Certified connected queries contract the represented binary64 gate matrices exactly as dyadic integers, then add a conservative ideal-unitary error bound from outward-rounded gate intervals. The update e′ ≤ e + δ + eδ follows by telescoping and submultiplicativity of the operator norm; represented-to-Float64 output error is bounded via exact dyadic subtraction. For norm-one observables, the ideal state contribution is at most e(2+e). The certificate admits the stated binary64 angle domain; it does not certify unknown user angle uncertainty or every engine path. The original test thresholds are retained. See `docs/COMPLEXITY.md` for explicit upper bounds and hard-regime limits.

Independent evaluators can submit a sealed `DSIQ-peer-v1` fixture to `node tests/peer-verify.mjs fixture.json`. It accepts complete circuit gates and externally supplied complex amplitude, log/phase, Pauli and norm expectations; the tool prints the exact input SHA-256 and actual comparison evidence and exits nonzero on errors or failed comparisons. Its local smoke test is not a blind or independent audit. External reference packages and hardware are still required for the original named cross-engine and peer tests. An example fixture is in `tests/peer-fixture-example.json`.

## v0.9 binary displacement-rank frame and encoded measurement

The new optional `rank-frame` mode constructs an invertible binary coordinate map D from the span of all conjugated Pauli X masks. It applies D to every Pauli generator, retains the exact phase and conjugated Clifford frame C D†, and removes Z mask components on permanently-zero coordinates. Scalar rotations are executed, not discarded. The result is the same physical state in a different computational basis, with no intentional amplitude pruning. T/TDG global phase is accumulated as a mod-16 exponent before conversion. Arbitrary irrational rotation entries remain FP64.

When the final frame is nonmonomial, the rank sampler row-reduces the mutually commuting images of the Z measurement generators. Independent inactive-X rows contribute uniform bits; the remaining rows act on the bounded active space. A second GF(2) symplectic elimination selects independent logical Paulis and determines dependent outcomes, including signs. Each independent logical measurement uses the full coherent projector (I±P)/2, and the physical bits are recovered from the recorded row operations. Conditional probability and sampling tests compare full distributions on small circuits and the encoded support of 100- and 1024-wire examples. Coefficient and work boundaries are enforced; the active dense sampling scratch is not viable at arbitrary rank. See COMPLEXITY.md.

No cancellation of the full random uncompute workload is counted. A high displacement rank can still exhaust the configured budget; this is not a general solution of #70.

## v0.10: direct basis streaming and native-host path contraction

The monomial frame now computes a basis amplitude directly by an exact binary address and phase transformation followed by a product of factor coefficients. `FrameFactorDSIQ.streamBasis(startBigInt,count)` streams a bounded range on demand (up to 1,048,576 entries); for a nonmonomial frame it uses the existing coherent query implementation. It does not allocate an entire register vector. `monomialDescriptor()` exports a copied numerical frame descriptor. `native/frame_stream.c` supplies a bounded 64-bit index block interface, useful for full-vector reference validation. The audit `OPENBLAS_NUM_THREADS=1 python tests/connected-frame-audit.py 25 local` reconstructs each amplitude of a connected non-Clifford circuit against a complete dense independent NumPy vector. The dense reference allocation is test-only. `native/bond_contract.py` admits one-wire and singly-controlled circuits, with bond, compact and affine constraint representations, array preflight and scaled FP64 tensor arithmetic (NumPy/BLAS). These are separate headless paths, not browser/GPU/MPI integrations. `node tests/bond-contract.test.mjs` compares numerical answers to another independently implemented dense reference on small circuits and the existing pair contractor on a 100-wire random depth-four prefix. The difficult depth-five case has an array forecast only; no depth-100 execution result is implied.

## v0.11 — untruncated QR matrix-product states and coherent native slicing

`native/mps_exact.py` is a separate headless CPU execution backend. For bounded-arity gates, it represents the physical vector as a chain of two-slice matrices, applies adjacent two-wire matrices (routing distant wires with reversible SWAPs), and retains **every reduced QR column**. No SVD tolerance, rank cutoff or benchmark-specific cancellation is used. Planning predicts explicit coefficient and scratch-array shapes from wire connectivity and rejects unaffordable requests. LAPACK scratch, Python metadata, and process RSS remain additional; floating-point roundoff and underflow remain possible. A right-canonical sweep enables conditional sampling via squared branch-vector norms. NumPy provides ordinary linear algebra, not a third-party quantum simulator.

`native/sliced_bond.py` projects a selected hyperedge contraction order onto every assignment of selected internal binary indices. The planner greedily reduces forecast live array bytes, charges all 2^s slices to the work budget, and rejects excessive work before evaluation. Every completed slice is evaluated numerically, with scaled intermediate tensors; the represented slice mantissas are summed exactly as dyadic rationals before conversion. That last addition is exact for the computed mantissas, **not** a proof of exact ideal quantum arithmetic. The preflight excludes BLAS and runtime overhead; it is a heuristic upper estimate for its modeled arrays, not a lower bound on all orders.

Full-width connected low-depth MPS circuits and a depth-100 connected chain with bounded bond crossings are tested separately. The original fully randomized 100-qubit depth-100 #70 requirement is unchanged; reduced-width random matching tests and sparse-chain inverse recovery do not replace it. The browser execution path does not yet incorporate these native Python backends.

`python tests/run-campaign.py --external` executes the original full acceptance harness plus the four new headless tests and installed named reference checks, writes timestamped logs, source SHA-256 hashes, and a fail-closed summary. It never installs dependencies automatically, never upgrades partial acceptance checks on the basis of an unrelated test, and does not loop indefinitely on missing hardware or independent evaluators. The original acceptance report remains authoritative.

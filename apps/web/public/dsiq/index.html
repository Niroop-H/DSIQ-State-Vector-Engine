Browser execution boundary
This interface executes the existing DSIQ JavaScript engine in an isolated browser Worker. No circuit inputs are uploaded to Vercel functions and no fabricated or precomputed result values are embedded in the interface. The v0.16 native binary128 research pipeline is separate and is not represented as browser execution.
State representations
The scientific worker exposes adaptive, contracted, frame, rank-frame, parity, dyadic and certified numerical variants. Individual methods admit different gate families, observables and resource bounds. Unsupported requests return an explicit error.
Reproducibility
Each completed experiment can be exported as a JSON evidence record containing the submitted circuit, query, execution parameters, machine-reported statistics, sampled counts, scientific outputs and SHA-256 source digest.
Validation and access
The Diamond-105 research qualification has not been declared complete. The browser workspace is publicly accessible for research evaluation. Its execution results come from the DSIQ worker; the separate native engine is not distributed through this interface.
